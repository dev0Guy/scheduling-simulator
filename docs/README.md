# docs

| Folder / file | What it holds |
|---|---|
| `experiment_log.md` | Chronological log of every experiment (#1 to #31), with diagrams in the visual guide |
| `experiment_tables.md` | Compact environment, model and result tables (E1 to E4, M0 to M10) |
| `all_experiments_summary.md` | Readable summary of the whole project |
| `current_architecture.md` | Description of the current network |
| `model_explained_for_beginners.md` | Plain-language explanation of the model |
| `ppo_vs_sjf_*.md`, `ppo_worse_than_sjf_episodes.md` | PPO vs SJF analyses and decision traces |
| `results/` | Small result tables (E1 SJF vs M0/M1, M5 to M10 on E4) |
| `environments/` | E2 environment write-up (`.tex`) and job-creation equations (`.md`) |
| `diagrams/` | SVG architecture, environment and result diagrams (generated) |
| `html/` | Interactive architecture pages |
| `presentations/` | `experiments_deck.pptx`, one slide per experiment |

Regenerate the diagrams and the deck with `scripts/docs_tools/` (see `scripts/README.md`).
