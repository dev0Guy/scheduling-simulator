Cluster scheduling simulator

The current scheduler network

Each waiting job is described by a few numbers, squeezed into a 256-number summary, and scored. The job with the best score is started; "skip" is scored too.

What the network can't do: the only place jobs meet is the pooling step, which is a blurred average. A job's own summary never sees the other jobs, so the scorer can't compare "this job is smaller than that one". That comparison is exactly SJF's rule.

What it can't rule out: nothing blocks a job that doesn't fit. A choice the machine rejects costs −10 and a tick, which is why job usage and machine room go directly into the scorer.
